# H3 OmniRef 分镜导演

把剧本变成“模型真的能拍出来”的分镜表。核心原则：**编排服从叙事，参数服从模型边界**。不考虑模型能力的漂亮分镜等于废纸。

## 一、模型边界（必须先过这一关）

| 项目 | 硬边界 | 后果 |
|---|---|---|
| 单镜时长 | 仅 5 / 8 / 10 / 15 秒（帧数 = 24×秒，向上取整到 17 的倍数：5s=124、10s=243、15s=362） | 其他时长会被取整，口型错位 |
| 15 秒 | 只能用低（768×432）或中（960×544）像素档 | 15s + 高像素（1344×768）本机 29 分钟跑不完 |
| 像素档 | 低 0.33MP / 中 0.52MP / 高 1.0MP；横 16:9 或竖 9:16 | 高档 10s≈10 分钟，5s≈5 分钟 |
| 参考图 | ≤ 9 张，每张一个主体 | 超了会丢引用 |
| 主体引用 | 每张图对应 `<Subject i>` 与 `<Picture i>`，编号必须一一对应 | 编号错位＝人物串脸 |
| 音频 | 模型强制生成音轨，不能关闭 | 空镜若不显式禁止，模型会自己编旁白 |
| 台词语言 | 支持普通话，但会跑出方言 | 必须写“标准普通话播音腔，禁止方言” |
| 台词量 | 单镜 ≤ 30 字较稳 | 超 40 字口型糊、语速赶 |
| 参考图权重 | 图会压过文字 | 文字没点名的角色，模型仍会画进来并抢主体 |

## 二、工作流

1. **读剧本，先定场次目标**：每场一句话说清“这场要让观众知道什么/情绪往哪走”。写不出来说明这场可以删。
2. **拆 beat**：每场按“信息变化点”切镜头。一个镜头只承担一个变化（新人物入场／态度转变／关键道具出现／信息揭示）。
3. **给每镜配六段**：镜头、画面、表演、台词、声音、落幅。
4. **定档**：按台词字数与动作复杂度选 5/8/10/15 秒，并同步选像素档。
5. **选参考图**：只放本镜真正出场的主体，最多 9 张；不出现的一律不放。
6. **自检**：跑第五节的 10 条体检规则，全部通过才算可生成。

## 三、六段写法

- **镜头**：景别＋视角＋机位运动＋焦段＋景深＋速度。例：`中景，平视，固定，50mm，中景深带出环境，常速`。
- **画面**：主体外观、动作、朝向、视线落点、光线与环境。**必须点名本镜关联的角色/道具**，用 `@角色名` 或直接写名字；一句里只写一个主动作。
- **表演**：一个微动作 + 一句动机。例：`放杯的右腕短暂停住，双肩向两侧打开——讲述由此起头`。空镜留空。
- **台词**：每行一条，必须带说话人和语气：
  ```
  @矮人酒保（低沉·慢速·句中停顿）说：「开店三十年，我见过有人拿着屠龙剑来买酒。」
  旁白（中速·画外）叙述：「先说好，今天只讲游戏里的彩蛋。」
  ```
  同一句只写一次，不要同时写进画面。
- **声音**：具体音效及其位置。例：`杯底碰上木台的“咚”声从画面下方传出，围裙摩擦声紧接掠过`。
- **落幅**：镜头结束时的画面状态，谁在哪、朝向谁、关键道具在哪。

## 四、提示词组装（严格按官方 Ref2VA 范式）

**唯一标准来源**：本技能目录下的 `references/h3_prompt_spec.md`（机器可校验版 `references/h3_prompt_spec.json`）。
生成提示词前先读它；**不得自行发明 section、标签或句式**。

只有六个 section，顺序固定：

```
subject_definitions:   <Subject 1> is the 场景 "酒馆大堂", shown in <Picture 1>: 酒馆大堂.
summary:               [reference generation] Single 8-second shot: ...
retention_analysis:    <Subject 1> (appears in [Shot 1]): fully_preserved - keep the 场景's appearance, colors and materials unchanged.
detailed_description:  [Shot 1] {overall style}. {画面/表演}. 牧师 (S1), 低沉·慢速, says in standard Mandarin: <d>[Chinese] 你倒是说句话啊。</d> {音效}. 落幅：...
overall_soundscape:    {环境音与物理音效}. Dialogue is in standard Mandarin only, no dialect, no subtitles.
non_diegetic_music:    N/A
```

四条硬规则：

1. **正文用英文**，只有 `<d>` 内的台词、画面可见文字、资产中文名保留原语言；
2. 台词必须 `<d>[Chinese] 逐字台词</d>`，说话人身份/语气/动作放在 `<d>` **外**，用稳定 ID `(S1)(S2)`；
3. 不出现在官方清单里的 section（`dialogue:`、`input_rules:`、`language_control:`）一律不许写；中文标签 `【画面】【台词】` 也不许用；
4. `non_diegetic_music` 无配乐写 `N/A`，不写 `no music`。

无台词 / 空镜分支直接写英文禁读句（见 spec 第 3 节），不要用中文“禁止朗读”。

## 五、体检规则（10 条）

1. 每镜有信息增量，否则标记废镜候选。
2. 空镜时长 ≤ 5 秒。
3. 空镜必须走“无台词分支”，不能只留空。
4. 关联资产必须在本镜文字中出现，否则生成时拦下。
5. 多角色镜头的台词必须标 `@说话人`，否则按旁白处理。
6. 单镜台词 ≤ 30 字（硬上限 40）。
7. 必须写景别/机位，否则结果不可控。
8. 连续三镜同景别要打破（节奏单调）。
9. 参考图只放本镜出场主体，且 ≤ 9 张。
10. 15 秒镜头不得选高档像素。

## 六、输出格式

先给一张总表，再给逐镜细节：

| 镜头 | 时长 | 像素档 | 参考图 | 一句话作用 |
|---|---|---|---|---|

逐镜按六段展开，最后单列“模型风险提示”（本镜可能踩的边界，例如：两人同框易抢主体、15s 建议降档）。

## 七、常见反例

- 空镜 10 秒且没写禁止人声 → 模型自己念旁白。
- 文字写“门口雨帘被推开”但参考图里放了酒保 → 成片只有酒保，没有新人物。
- 台词写两遍（`dialogue` 与 `【台词】` 都放原文） → 模型念两遍。
- 用带有方言口音的形容词（“东北大汉”） → 台词带口音。
- 15 秒 + 1344×768 → 跑不完，先降档或改 10 秒。
